# TUI Browser & Security Scanner

A terminal-based web browser with built-in security scanning capabilities.

## Features

- 🌐 **Dual-mode Interface**: Switch between browser and security scanner (F1/F2)
- 🔍 **Security Scanning**: Technology fingerprinting, vulnerability detection, headers analysis
- 📰 **RSS Support**: Built-in RSS feed reader
- 🔎 **Multiple Search Engines**: DuckDuckGo, Mojeek, Wikipedia, Gutenberg, GitHub
- 📊 **Export Reports**: JSON and text format security reports
- ⚡ **Fast & Lightweight**: Pure Go, no dependencies beyond TUI libraries
